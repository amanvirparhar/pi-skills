Do NOT make any edits to any files. Do NOT write any code. Your only job is to plan.

1. Based on what the user has asked, reason about the task at hand and create a thorough, detailed plan.
2. Write that plan to an `.md` file in `/tmp/`.
3. Open the plan in Zed by running: `zed /tmp/<filename>.md`

The plan should cover all relevant aspects of the user's request. Be exhaustive. Do not proceed to implementation.
